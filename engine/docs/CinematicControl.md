# Управление во время катсцены

Политика лежит в `Engine/PlayerControl.h`. `VitaEngine` передаёт её камере,
персонажу и системе дверей каждый кадр. Флаги движения, осмотра и взаимодействия
отдельны от владельца позы. Запрет ходьбы сам по себе не запрещает физику;
поза под управлением катсцены исключает игровую гравитацию, коллизию и idle.

```cpp
// При старте. Повторный Begin во время активной сцены вернёт false.
engine.BeginCinematicControl(PlayerControl::FullCinematic());

// Следующий фрагмент: персонаж продолжает сценарную анимацию,
// игрок вращает обычную камеру вокруг него, ходить и открывать двери нельзя.
engine.SetCinematicSegmentControl(PlayerControl::CameraOnly());

// Завершение, пропуск и ошибка должны проходить через этот же вызов.
engine.EndCinematicControl();
```

`End` восстанавливает предыдущие разрешения, а не всегда включает всё.
Режим свободного полёта временно запрещён и затем восстанавливается.
Ручные настройки `PlayerControl` позволяют оставить обычную позу персонажа,
запретить ходьбу, но разрешить взаимодействие. Не разрешайте `cameraLook`
при `cameraPose == Cinematic`: добавление пользовательского смещения к нативной
камере пока не реализовано. `CameraOnly` использует обычную орбитальную камеру.

Анимацию сценарного персонажа проигрывает будущий проигрыватель катсцен:
`FindAnimationClip(name)` вызывается один раз при загрузке, затем
`SampleCinematicPose(index, time, modelWorldPosition, visualYaw, dt)` каждый кадр.
Позиция здесь относится к модели (apReference), не к локатору и не к итоговой
мировой позиции корневой кости. Существующий контроллер ходьбы её не перезаписывает.
Для возврата к игровому клипу потребуется передать позицию итогового корня и
перебазировать позу; нельзя просто назначить локатор как PlayerStart.

Экспортёры катсцен записывают `stage.control`: события с локальным временем,
владельцами поз и отдельными разрешениями. Это настройки порта, помеченные
`port_authored_not_recovered_script`; исходные переключения управления и
задержки сценария не расшифрованы. По умолчанию вся сцена закрыта для ввода,
при выходе политика восстанавливается. Настраиваемые события создаются через
`tlou_extractor.cinematic_control.control_track`:

```python
stage['control'] = control_track(stage['duration'], [
    (0, 'full_cinematic'),
    (20, 'camera_only'),  # пример вручную выбранного момента, не время из игры
])
```

Пока сцена спальни воспроизводится в браузерном тесте. Движок не читает этот
JSON и не запускает её автоматически после вступительного видео. Добавлены
политика и точки подключения; проигрыватель катсцен должен вызывать Begin,
SetSegment, SampleCinematicPose и End, а также отдельно задавать камеру.
Звонок и русские реплики не привязаны. Извлечённые исходные XVAG сохранены
рядом со сценой, с неизвестным временем запуска. Лицевые вторичные потоки
и параметры объектива пока не восстановлены.
