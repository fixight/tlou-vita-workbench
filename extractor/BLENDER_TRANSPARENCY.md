# Стекло и растительность в Blender

Откройте `scene_alpha_preview.blend` и включите Material Preview:
Z → Material Preview (значок сферы в правом верхнем углу 3D View).
Rendered тоже учитывает маски. Solid предназначен для геометрии и не
показывает эту прозрачность материалов.

В этой версии подключены исходные отдельные маски g_tNdFetchTransparencyMap:
98 текстур, 2224 используемых материала. Маска читается из красного канала
как линейные данные Non-Color. Цветовая текстура и запечённый свет сохранены.
Чёрный маски означает прозрачную часть, белый — непрозрачную.
У стекла сохранены исходные промежуточные значения.

Чтобы переключать прозрачность из панели:
1. В Text Editor выберите blender_streaming_tools.py и нажмите Run Script / Alt-P.
2. В 3D View: N → TLOU → «Материалы: стекло и растительность».
3. «Прозрачность из исходных масок» включает/выключает все подключённые маски.
4. Для выбранного материала доступны «Без», «Отсечение», «Плавно».
   Плавно — исходная карта непрозрачности; отсечение — пороговая маска.
   Изменив множитель или порог, нажмите «Применить параметры».

Отсечение полезно для карточек листвы; плавный режим сохраняет полупрозрачность
стекла и мягкие края. По умолчанию используется плавный режим: оригинальные
состояния alpha-test/alpha-blend и пороги шейдеров пока не расшифрованы.
Это восстановление непрозрачности, а не полного шейдера стекла с отражениями
и преломлением. Режим прозрачности не отключает запечённое освещение.

Рядом с .blend должны оставаться textures/, static_lighting/ и opacity_masks/.
transparency.json хранит точные привязки масок к исходным материалам;
transparency_summary.json — отчёт применения. Существующие scene.blend и
scene_player_preview.blend не перезаписаны.

Для новых PS4 экспортов парсер сохраняет transparency_hash и экспортирует
полноразмерную PNG маску. GLB содержит nd_transparency_uri в extras материала;
наш blender_export.py подключает эту карту автоматически, включая материалы
с запечённым освещением.
