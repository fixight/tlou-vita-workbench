# Предпросмотр стриминга по позиции игрока

Откройте `scene_player_preview.blend` из этой папки. В Text Editor выберите
`blender_streaming_tools.py` и нажмите Run Script (Alt-P). Вернитесь в 3D View:
N → TLOU → «Позиция игрока → стриминг».

Для Остина выберите семейство главы `hom`. Оно выбирается автоматически
по преобладающим загруженным участкам; для другой главы выбор можно изменить.

1. Нажмите «Создать / выбрать игрока», затем включите «Симуляция позиции».
2. Перемещайте зелёную сферу TLOU_PLAYER_PREVIEW клавишей G (G, X/Y/Z ограничивает ось).
   Её центр — проверяемая позиция игрока. Можно задавать координаты в панели Item.
3. Для прогулки от первого лица включите «Позиция из камеры обзора», затем
   используйте View → Navigation → Walk Navigation (обычно Shift-`).
   Проверяется позиция камеры обзора, поэтому нужно находиться внутри объёма,
   а не просто смотреть на него издалека. Отключите этот режим для перемещения сферы.
4. Включите «Области стриминга», чтобы видеть настоящие дочерние объёмы.
   Выбрав объём, нажмите «Игрок в выбранную область» для быстрого перехода.
5. Панель показывает активные области и изменения набора ресурсов.
   Подробности: Text Editor → TLOU_PLAYER_PREVIEW.json.

Симуляция проверяет точку против плоскостей выпуклых объёмов, с допуском
на float32 координаты исходных файлов. Несколько объёмов области и пересекающиеся
области объединяются. Общий ресурс остаётся требуемым, пока нужен хотя бы одной
активной области. display отображается, resident_only учитывается без показа.
Чужие главы, которых нет в загруженной геометрии, исключаются по семействам
исходных уровней и ссылкам на присутствующие чанки.

Для константных селекторов используется исходное значение. Для условий,
требующих состояния игры, N задаётся вручную в свойствах выбранной области.
Несуществующий N отмечается в отчёте и не подменяется другим набором.
По умолчанию вне всех областей сохраняется последний набор: это настройка
предпросмотра, а не доказанное правило оригинального движка. Отключение этой
галочки позволяет увидеть пустые участки между объёмами.
Быстро пересечённые между замерами области перечислены в crossed_between_samples;
они не активируются как будто игрок остался внутри.

Это работающий предпросмотр геометрии и ресурсных наборов, не точная эмуляция
сценария Naughty Dog. Приоритеты пересечений и смысл комбинаций нескольких
объёмов ещё не расшифрованы. Прочие (gameplay) области дают только события
входа/выхода; катсцены и скрипты не запускаются. Коллизия со стенами и капсула
персонажа здесь не реализованы. Чанки скрываются, но не освобождают память Blender.
Некорректные/невыпуклые объёмы пропускаются с причиной в geometry_errors.
Не добавляйте модификаторы к объёмам: проверяется исходный mesh; перемещения,
повороты, масштаб и редактирование вершин поддерживаются.

Ручной выбор участка и кнопки пошагового маршрута отключают симуляцию,
чтобы два режима не меняли видимость одновременно. Повторный запуск скрипта
заменяет старый таймер и обработчик. После открытия файла симуляцию нужно
включить вручную. Исходный scene.blend сохранён без изменений.
