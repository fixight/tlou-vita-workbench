# TLOU Vita: исходники движка и извлечение данных

Актуальный снимок работы на **8 октября 2026 года**. Включает незакоммиченные
изменения обоих проектов: рендер, SK16, анимации, двери, JobSystem, стартовую
загрузку, аппаратное видео, AudioManager и VCN v3 с камерой, управлением и звуком.

## Быстрое восстановление

```sh
git clone --recurse-submodules REPOSITORY_URL TLOU-Vita
cd TLOU-Vita
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r extractor/requirements.txt
python -m pip install capstone
cd extractor
python serve.py
```

На Windows активация окружения: `.venv\Scripts\Activate.ps1`.
Просмотрщик: http://127.0.0.1:8080/viewer.html. В нём нет встроенных моделей;
импортируй PAK или заново извлеки модели. Его реализация сохранена целиком.

Движок собирается в Linux/WSL с VitaSDK. Подробный порядок, получение ресурсов,
рецепты катсцен, ограничения восстановления и проверки — **[RESTORE.md](RESTORE.md)**.

## Где что находится

| Папка | Содержание |
|---|---|
| `engine` | C++17 движок, тесты, сборщики runtime-форматов, документация |
| `extractor` | Python-парсеры, браузерные просмотрщики, Blender-инструменты, исследования |
| `recipes` | Сохранённые настройки телефонной сцены и сведения об исходном видео |
| `scripts` | Восстановление катсцен и проверка целостности исходников |
| `dependencies` | Закреплённые Git-подмодули vitaGL и vdpm |

Актуальный Blender-экспортёр: `extractor/tlou_extractor/blender_vita_export.py`.
Копия в `engine/tools/blender` может отставать; не заменяй ею актуальный файл.

## Что намеренно отсутствует

Образ игры, PAK/PSARC, модели, текстуры, звук, видео, Blender-сцены, runtime-бинарники,
сборки VPK и установленный SDK. Их можно получить повторным извлечением/экспортом.
Оригинальная история Git не перенесена: в старых коммитах есть viewer со встроенными
ассетами. Снимок содержит текущие исходники; базовые SHA записаны в
`dependencies.lock.json`, список файлов — в `snapshot-inventory.json`.

**Один clone не даст готовую игровую сцену.** Правки, сделанные только вручную внутри
`.blend`, не восстанавливаются из C++/Python. Они не включены по условию «без ассетов».
Для продолжения программирования исходников достаточно; для запуска понадобится
образ игры и повторная подготовка уровня. Не удаляй единственную копию образа,
если рассчитываешь снова получить ресурсы.

`installed-library-fingerprints.json` фиксирует контрольные суммы библиотек старого
SDK для сравнения. Это не архив SDK и не гарантия идентичной сборки на новой версии.
